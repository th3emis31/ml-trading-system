2. Restart router (unplug 30 seconds)
3. Reopen browser
4. Try again at: http://127.0.0.1:5001/jarvis-voice

**Or:**
1. Try different browser (Firefox instead of Chrome)
2. Try private/incognito mode
3. Check if firewall is blocking
