# How to Use JARVIS Voice on Your Laptop - Simple Steps

## Step 1: Open Your Browser
1. Look at your laptop desktop
2. Find and double-click one of these icons:
   - **Chrome** (colorful circle)
   - **Firefox** (orange/red fox)
   - **Edge** (blue swirl)
3. Wait for browser to open

## Step 2: Go to JARVIS Voice Page
1. In the address bar (top of browser), paste this address:
```
http://127.0.0.1:5001/jarvis-voice
```
2. Press **Enter** key
3. Wait for page to load (may take 5-10 seconds)
4. You should see JARVIS logo and a big microphone

## Step 3: Allow Microphone Permission
1. Browser will ask: "Allow microphone access?"
2. Click **"Allow"** (blue button)
3. Your laptop microphone is now ready

## Step 4: Use Voice Commands
1. Look for the big circle with microphone icon
2. Click the microphone circle
3. When you hear a beep or see "Listening", speak:
   - **"Hey JARVIS, hello"**
   - **"Hey JARVIS, what time is it"**
   - **"Hey JARVIS, analyze EURUSD"**
4. JARVIS will listen and respond

## Troubleshooting

### If page doesn't load:
1. Make sure you typed the address correctly
2. Try again (may need 5-10 seconds)
3. Try refreshing: Press **F5** key

### If microphone doesn't work:
1. Make sure you clicked "Allow" for microphone
2. Check your microphone is not muted
3. Try speaking louder
4. Make sure it says "Listening" before you speak

### If JARVIS doesn't understand:
1. Speak more clearly
2. Say "Hey JARVIS" first, wait for it to acknowledge
3. Then say your command

## If Still Getting "Error: network"

This means browser cannot connect to Google speech service.

**Quick Fix:**
1. Close browser completely
2. Wait 10 seconds
3. Reopen browser
4. Go to: http://127.0.0.1:5001/jarvis-voice
5. Try again

**If still error:**
- Try different browser (Firefox instead of Chrome)
- Restart laptop completely
- Or try from different WiFi (phone hotspot)

## Desktop Shortcut (Optional)

Want easy access? Create a shortcut:

**Windows:**
1. Right-click on desktop
2. Select "New" → "Shortcut"
3. Paste this:
```
http://127.0.0.1:5001/jarvis-voice
```
4. Click Next, name it "JARVIS Voice"
5. Click Finish
6. Now double-click it anytime
